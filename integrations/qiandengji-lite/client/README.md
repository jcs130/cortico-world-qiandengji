# 千灯纪 1.21.1 配套客户端

发行页的 `.mrpack` 是供图形启动器导入的独立客户端配置包，包含已验证的 Fabric、YSM、性能优化、语音和原生观战组件。Minecraft 与 Java 由启动器取得；第三方模组从官方链接按原 SHA 校验下载。不要覆盖正在使用的 Agent 游戏目录。包内没有本机账号、凭据、Agent 记忆、地图存档或模型原包。

先在支持 `.mrpack` 的启动器中导入，再用自己的 Minecraft 身份启动 Minecraft 1.21.1／Fabric；选择自己原来的千灯纪服务器与注册账号。游戏服务器密码与微软账号密码不同。没有账号时走服务器官网／正常注册，不让客户端创建或重置角色。

默认是普通游玩配置：观战控制关闭，不改变角色职业或游戏模式。Cortico World 与图形端不能同时使用同一个用户名；Agent 原身体继续由 World 控制，真人使用自己的账号，观战使用另一个已注册的 `xxx_eye` 账号。

包内 `qiandengji-client-tools/` 提供可选本机配置工具，需要 Node.js 22 以上。`--game-dir` 填启动器中这个独立配置包的实际游戏目录，服务器地址必须与服务器列表完全一致，并明确写端口。请替换下列示例，不要照用示例地址或用户名。

普通玩家：

```sh
node configure.mjs --game-dir <游戏目录> --mode player --server <服务器:端口> --username <本人用户名>
```

观战：

```sh
node configure.mjs --game-dir <游戏目录> --mode observer --server <服务器:端口> --username <本人名字_eye> --targets <玩家一>,<玩家二>
```

观战完整用户名最多 16 位，`_eye` 前至少一位。名单须明确、最多 16 人且不包含本人。配置只开启本机显示与固定镜头入口；旁观、跟拍、只读数据及交互限制由服务器实际授权。不会通过改名或客户端命令获取 OP／绕过鉴权。原特殊 `live` 账号及其凭据不会随包分发，也不是新用户的观战模板。

配置后重新连接客户端。实际收到本连接 `MC_AUTH_SUCCESS` 后，可按 F9 切换被跟拍对象的详细信息，F10 翻页。缺失或陈旧信息仍为未知，不从其他玩家或历史缓存补数。左上角小人使用实际镜头目标的模型与动作。普通游玩模式不会开启跟拍控制。

可选的单次镜头请求：

```sh
node request-camera.mjs --game-dir <游戏目录> --target <名单中的玩家> --view drone_follow
```

镜头支持 `first_person`、`third_person_back`、`third_person_front`、`drone_follow` 和 `drone_overview`。请求只控制原观战者，使用新连接绑定和短期请求号，不启动玩家或大模型。查看打印出的原生回执路径，核对同一 id／lease、终态和实际 cameraUuid；提交、排队和受理都不等于镜头已成功附着。未知结果只查询原请求。手动退出跟拍会保留暂停，不循环抢回镜头。这些是固定镜头能力，包内没有声称已经完成 VLM 导演或任意无人机导航。

Windows 可选自动登录：先完成上述本机配置，再在自己的终端运行 `configure-password.ps1 -GameDir <游戏目录>`。输入原服务器密码一次；工具使用当前 Windows 用户 DPAPI 保存二进制密文，配置中只有文件引用。账号、服务器不匹配时不读取；收到明确错误密码或二步验证后停止重试。其他平台可使用游戏内正常登录。不要将产生的 `config/private/`、账号配置、日志或记忆重新上传进公共包。

此版默认上限 60 帧，Sodium、Lithium、FerriteCore、ImmediatelyFast 已做组合验证，默认不启用光影。不同硬件、场景和录播负荷的帧率仍需现场验证；本机 AMD 实测约 59 帧不代表所有硬件保证 60 帧。配套包不携带本机专用 AMD 运行时、DLL 或驱动，也不改任何显卡设置。

服务端兼容：本批正式入口实测匹配 YSM 2.4.1（21 项模型目录、真实角色和跟拍）。YSM 2.6.5 的 AMD 单人组合已通过，但正式入口实测仍停在等待模型同步，不能靠客户端单独换包完成升级。正式客户端暂使用匹配版本；2.6.5 原包、走跑／攻击／持物动画及正式服配套切换仍待联测。模型由服务器同步原作者资源，不附带、解密或重建《大肥鱼 1.1》。
