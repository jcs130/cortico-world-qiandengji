# 配套 Java 客户端

从 https://mc.kangqiang.site/downloads.html#game-clients 下载官网当前的配套整合包，使用自己的启动器按官网说明导入。普通真人玩家使用原账号；观战使用 xxx_eye，权限由服务器授予。Agent World 与图形客户端不要同时使用同一账号。

Java、Minecraft、模组、YSM 与服务端模型链版本以官网当期配套为准；此 World 版本不会启动旧版下载清单或降级现役客户端。源码中保留的早期配置脚本用于历史兼容，不作为新安装入口。本包只保留客户端说明和旧 World 配置迁移脚本；图形客户端分别从官网获取。
