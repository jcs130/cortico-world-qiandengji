# 技能基础：先查说明，再尝试

千灯纪有公共基础技能和战士、法师、牧师方向。技能可能需要学习资格、技能点，并消耗魔力或有冷却；不要因为看过名称就认为自己已经学会。

1. `/mycli skills status`：查本人的技能、魔力和冷却。
2. `/mycli skills list common 1`：看基础技能列表；按回执翻页。
3. `/mycli skills info <ID>`：查一项技能的效果、条件、费用及操作命令。
4. `/mycli skills points`：查可用技能点；学习、升级、准备和洗点按当前说明操作。

例如想了解飞行，先发 `/mycli skills info flight`。施法可以按详情里的命令进行，真人也可以用技能罗盘。查询不会自动学习；学习和施法后要核对回执、资源与现场效果，不能把“命令已发送”当作技能生效。

高级技能、独特技能和解锁方法，留在游戏里通过 NPC、任务、事件与练习发现。本页不列任务答案、预设加点路线或固定效果数值；更完整的当次目录仍从 `/mycli` 获取。
