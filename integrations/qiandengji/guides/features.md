# 特色能力的发现与核验

本页是维护者依据千灯纪服务端源码资料整理的入口（2026-10-26，`minecraft-ai-friend` 主分支 `79b30f98`）。它不是本角色的已学技能清单；费用、资格和命令先以本连接的 `/mycli --help`、`/mycli capabilities`、对应分组 `--help` 和本人状态核对。一次只展开要用的能力，不全量重读目录。

| 需求 | 先读取什么 | 执行与生效证据 |
| --- | --- | --- |
| 客户端截图 | `mymc_photo` 的参数、`mymc_guide vision` | 返回图片、拍摄时间与视角；截图不是游戏内地图物品 |
| 游戏内拍照 | `/mycli photo --help`；资料入口为 `/mycli photo menu` | 服务端拍摄与个人奖励箱回执、成片；打开菜单不等于拍成 |
| 写书、游记与档案 | `/mycli life --help`、`/mycli archive --help` | 资料中的 `life write <书名>\|<正文>` 消耗书与笔，生成署名书；先核对现役语法和材料。核验书的作者、标题、正文与物品净变化，不把聊天当写书 |
| 飞行 | `/mycli skills info flight`、`mymc_guide flight` | 已学/准备、魔力、冷却、当前可飞状态；用 `mymc_flight_plan` 核对航线和落点，真实抵达并安全着陆才算结束 |
| 闪现 | `/mycli skills info blink`、`mymc_guide travel` | 依当次说明先观察并朝向安全方向；核验位置与资源变化，不擅自添加坐标参数 |
| 学习、升级和准备 | `/mycli skills status`、`/mycli skills points`、`/mycli skills info <ID>` | 区分图鉴存在、已解锁、已学习、已准备、当前可施放；查询不会花点或代学 |
| 职业选择 | `/mycli profession --help`、`/mycli profession status` | 按本人意向和资格选择，再查职业及可准备技能；不要为检查随意选职或退出 |
| 洗点 | `/mycli skills --help` 中的 respec 说明、本人点数和战斗状态 | 明确理解会清掉哪些学习与准备、保留什么以及成本后才确认。读取帮助不等于确认，超时先查原结果，不重复消费 |

技能罗盘中的图标是菜单按钮，不是可取走的物品；菜单不能读或操作时，使用服务端给出的文字入口，不猜槽位或合成配方。历史技能缓存缺项只说明没有观察到，不能推断服务器没有该能力。学习后按需保存带来源、时间和适用条件的方法；下次使用前只刷新魔力、冷却、装备等易变状态。
