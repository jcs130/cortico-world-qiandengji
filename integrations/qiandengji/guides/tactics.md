你可以自己编写、试验、修订和保存快战术。用真实现场与回执决定策略，编写者是你，快模型负责在你构造的候选中做即时选择，执行器按当前身体控制权执行。已知连续动作也可用 mymc_script 自主编排；新的身体任务会取消旧脚本，不能靠反复插队维持动作。

## 程序入口

`mymc_combat_tactic {}` 读取当前程序源码、参数、版本及运行错误；`{"battlefield":true}` 读取当前直接战场。`{"program":{"name":"你的方法名","code":"JavaScript 同步函数体","params":{}}}` 编译并按世界保存程序，不需要重启。保存不代表战术已验证；`{"program":null}` 移除程序。语法失败不会覆盖旧设置。运行失败会停止采用该程序并告知你，默认候选作为回退；修订 program 才恢复试验。

程序作用域只有 `frame` 和 JSON `params`，返回 `{candidates:[], instructions:"给快模型的选择说明"}`。`frame.battlefield` 是当刻位置、生命、饥饿、附近实体的类型、位置、距离、视线、生命和已确认关系；null 是未知，在线或在附近不能证明同队。`frame.skills` 是可用性、魔力消耗、冷却和暂缓原因；`frame.mana` 是当前读数。`frame.actionPool` 提供当前可以执行的动作，`frame.candidates` 是默认回退候选，`frame.tacticRevision` 标识本版。

你可以读取完整字段后自行设计条件、挑选目标、重排或筛选候选、改写 intent，决定给快模型提供哪几项以及如何权衡。返回空 candidates 表示这次不请求快模型。最多返回16项，发送时按当前 maxCandidates 截取；instructions 最多1200字符，intent 最多240字符。代码最多12000字符，参数最多4096字符。每次评估是新的隔离作用域，无文件、网络、模块、原始 bot 或异步调用，评估限时50毫秒；程序不应等待、循环直到现场变化或直接输出聊天。

## 动作与控制权

每项有稳定且唯一的 `id`、`kind` 和 `intent`。优先复制 actionPool 的动作对象并改 intent：

- `cast` 保留当前可执行动作的 spell、ruleId；条件分支通过同一工具的 rules 自己编排。没有学会、魔力不足或冷却未到的法术不能由程序变成可执行。
- `engage` 保留当前候选的 targetId 与 uuid；有其他身体任务时不抢占它。接敌后由战斗控制器持续追击和攻击。
- `retreat` 只在当前允许撤离时使用，执行现役撤离控制器。
- `step` 可选池中的八向短步，也可自己构造绝对 `destination:[x,y,z]`。位移0.5–1.6格，同一水平高度，全程需要已加载、实体宽度净空及实心支撑。客户端在选择前后和执行时复查。它直接按方向键，最长700毫秒，继续近战；没有逐格寻路或主模型等待。

程序短步不必等待1.5秒无命中。`battlefield.action.canStep` 为 false 时不能夺手：可能正在吃东西、挥刀、远程发射或寻路持有方向，也可能是普通身体任务的 attack。已有攻击的控制权与生命危机仍优先。根据真正可用的接口编排，不假定能同时控制多个身体执行器。更长或非战斗的按键序列使用 control 与 mymc_script，参数查 mymc_help 和 control 主题。

## 反馈、检索与修订

`{"decisions":true}` 读取本次进程最近八次快速选择摘要，`{"decision":编号}` 展开实际输入、程序名/源码哈希、版本、模型耗时、受理结果及一秒后的位移、生命、目标和身体任务读数。`sent` 只表示控制器受理；observation 是之后测到的变化，其他动作也可能同时发生，不能据此独占击杀归因。`{"report":战斗编号}` 展开整场命中、生命、施法回音和终态；战斗回执保存结束时战术，因此中途修改还需结合 decision 的版本辨认。

遇到死亡、无进展、技能受阻或新场景时，先查你自己的方法索引，读取对应源码和以前的适用条件。选择一项有依据的修订，保留旧源码及参数，在自然出现的适用场景执行，比较位移是否有效、命中、受伤、消耗、撤离与目标推进，不为验证专门制造危险。无效时修正前提或恢复旧版；有效范围有限就如实记下。

工作区方法库由你维护：源码、参数、目的、适用条件、父版本、源码哈希、观察时间、decision/战斗编号、实测结果与尚未验证项分别保存，在当前世界 methods/index.md 留入口。先标候选或待验证，复用时读回证据；同场景未再执行或未改善，不能标为提升。你可以调整这些方法和复盘方式。模型权重训练、引擎源码修改及服务重启目前没有开放给本工具。
