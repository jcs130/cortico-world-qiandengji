# 0.3 迁移边界

v0.2.x 的产品名、默认 World、MCP 入口与工具面向千灯纪；v0.3.0-next.1 改为通用 **Agent MC World**。

| 项目 | 0.2.x | 0.3 通用包 |
| --- | --- | --- |
| 包名 | `cortico-world-qiandengji` | `agent-mc-world` |
| Cortico World / 配置 | `mymc` / `worlds.mymc.*` | `mc` / `worlds.mc.*` |
| 工具 / MCP 资源 | `mymc_*` / `mymc://` | `mc_*` / `mc://` |
| 独立进程 | `qiandengji-mcp` | `minecraft-agent-mcp` |
| 账号 | 默认补 `ag_` | 原样使用配置的用户名 |
| 服务器规则 | 内置千灯纪适配 | 默认不假设，按帮助与回执学习 |

**不自动升级现役可米。** 现役账号、目标、记忆、账本、配置和连接仍使用原部署；本次源码拆分不触发重载。需要迁移时另行核对插件声明、工具名、环境变量、快战术和历史方法引用，并获得本线程范围匹配的加载授权。

`integrations/qiandengji/` 保留旧 World、配置、玩法目录与 MCP 装配供现役兼容，不在通用发行包内。工作区旧 `src/world.ts` 等转发到它，已有缓存模块读取的旧指南也保留。兼容源码可用不等于已完成通用部署迁移。

不要机械重命名历史记忆中的服务器事实；保留世界身份、时间、作者和来源。旧法术/战术程序需要实际服务器能力，不能通过改工具前缀就假定可在别服使用。
