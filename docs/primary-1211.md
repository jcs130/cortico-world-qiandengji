# Java 1.21.1 主维护版本

1.21.1 是默认维护、构建和验收目标，1.20.6 保留显式兼容回归。可选服务器扩展继续通过公开 SDK 消费独立核心，当前候选以中立包 package.json、工作区锁和来源清单为准。

外观和观战接收器依赖已校验的服务端 schema、本人 UUID/实体和真实 camera 状态，移除只允许 1.20.6 的接入判断。模型版本、原文件和归档 SHA、身份与过期检查保持。本人挥手从当前连接的真实序列化器探测 `arm_animation`，不再硬编码 Java 版本或包编号；不支持的编解码器不会猜测动作。

默认测试身体使用 1.21.1 注册表；第一/第三人称外观传输与 OBS 观战状态、手持/关闭/换目标清理分别覆盖 1.21.1 和 1.20.6。观战对象必须同时得到服务器授权与实际 camera 包确认。

共享观察器、外观与动作源码统一维护在 mc-visual-console，本扩展只锁定经检查的共享副本。版本来源和逐文件 SHA 记录在 engine/viewer-appearance.provenance.json；完整核心包来源记录在 vendor/core-source.json。普通 Minecraft 仍由独立核心负责，服务器资料和规则不进入核心。
