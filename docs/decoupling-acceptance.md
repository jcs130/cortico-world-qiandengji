## 行为覆盖

| 要求 | 证据与断言 |
| --- | --- |
| 无框架构建 / 类型 | 干净目录不复制 `.sources`、`engine`、`node_modules`；依赖树不存在 Cortico；Bundler 与 NodeNext 消费公开声明时禁止框架模块解析。 |
| SDK / MCP 一致 | 同一请求的执行回执、原文附件、触发与控制元数据经过 SDK → MCP → 真实 child IPC；MCP 结构化字段保留协议版本。 |
| 真实回合 | beginTurn/endTurn 显式控制；单个工具返回不结束整轮；重复结束不会再次执行边界钩子；工具屏障需要宿主确认。 |
| 任务与目标 | 受理、执行状态和终态独立传递；执行回执始终不冒称目标完成；目标 revise 校验版本并归档前后原文。 |
| 等待 / 停止 | 信号到达等待请求；停止关闭生命周期、阻止迟到启动和旧子进程复活；旧连接事件只归档。 |
| 当前事实 / 原文 | 动态事实按键替换；稳定前缀与尾部事实分开；预算计入工具描述、Schema 和预留输出；完整原文可查。 |
| 去重 / 迁移 | 请求先记 pending 再执行，未知结果不自动重放；同 id 参数不一致拒绝；旧数据复制到新目录并逐文件校验，原文件不改写。 |
| 默认网络边界 | 编译后默认 SDK 的导入、工具发现、事实读取与关闭在禁止网络的进程通过；未配置演出端点不扫描；显式配置的 relay 也不在构造时联网。 |
| 服务器频道 | viewer 未配置服务器扩展时不注册或请求 YSM/观战频道；显式扩展保留原始资源、当前 bot 绑定与关闭清理。 |
| 同一 bot 画面 | mock 同一 bot 的区块、实体、原生窗口、手持和外观回执测试通过；不创建第二个游戏账号。 |

测试使用模拟世界、局部物理和本机 HTTP/IPC。既有方法 IPC 测试尝试的是拒绝连接的 loopback 端口 1；没有接入真实 Minecraft 服务器。“离线”指不依赖外部网络与实服，不表示测试不使用本机 socket。依赖安装需要已有 pnpm 缓存，不宣称从空缓存离线安装。
