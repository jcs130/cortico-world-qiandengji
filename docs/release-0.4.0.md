# 0.4.0 安装包与部署记录

维护对象：`package.json`、`scripts/build-extensions.mjs` 与两个 World 包的 manifest。核对日期：2026-10-13。

## 包与接口

| 包 | 默认入口与依赖 |
| --- | --- |
| `agent-mc-world@0.4.0` | 中立 SDK；SDK/MCP、agent-mc/v1、独立核心、现代画面；无 Cortico 依赖 |
| `cortico-world-minecraft-agent@0.4.0` | Cortico API 5，World ID `mc`，工具 `agentmc_*`；自动安装同版核心 |
| `cortico-world-qiandengji@0.4.0` | Cortico API 5，World ID `mymc`；显式千灯纪服务器扩展与同版核心 |

两种 World 在 Cortico 中用包名安装，重启加载，分别配置 `worlds.mc` / `worlds.mymc`。保留原框架的 Minecraft 示例世界，不修改或覆盖它。未配置服务器不会连接，未配置演出桥不会扫描端口。

## 本轮修正

- 服务器包装包编译自己的模块，通过公开扩展端口依赖核心；移除邻接源码目录要求和私有包标记，补齐 API 5 manifest、搜索关键字、许可证与面板。
- 无效 `mc_goal` 参数返回结构化失败；宿主判断结案与环境条件核验分开，回执元数据明确 `semanticGoalVerified: false`。失败观察和未命中不证明区域安全。
- 受阻时的背包原文保留物品实例名称，不把普通玩家头改成大背包；随身容器校验迁至千灯纪扩展，由中立受理接口调用。
- `needs` 明确只引用本次数组内更早步骤，敌对类别参数明确为 `hostile`。
- 更新共享 viewer 的 HUD、头颅 profile 和原始贴图支持；保留物品组件预算，贴图仅在显式配置后读取当前连接已收到的身份。
- 公开服务器扩展端口与完整声明不引用本机 pnpm 内部路径。
- 原生依赖的声明兼容副本单独保留在 `vendor/native-types`，附版本、原始/修正哈希与许可证；不修改依赖运行代码。公开类型使用严格检查，不靠跳过依赖声明验收。
- 用户界面统一为“联机版我的世界”，保留 npm 包名和 `mc` / `mymc` 配置标识；现代页面随 World 提供。
- 通用 Cortico 适配器的 `agentmc_*` 前缀避免与内置示例工具重名，SDK/MCP 保留 `mc_*`，千灯纪保留 `mymc_*`；证据与归档原文不因适配器命名被改写。

## 阶段

- 源码：独立维护核心与中立协议完成；原 Cortico Minecraft 示例未修改。
- 构建：全新 `release-0.4.0-rc4` 目录使用离线依赖缓存，无 Cortico 安装或源码，构建、类型与包边界校验通过。
- 离线回归：65 个测试文件、458 项通过；涵盖 SDK/MCP/真实 IPC 一致性、真实回合、可取消等待、停止后不复活、事实预算与默认无隐藏网络调用。
- 公共类型：8 个代码入口在 Bundler / NodeNext 两种模式下使用 `skipLibCheck: false` 通过；禁止 Cortico 模块解析。
- 共享画面：`mc-visual-console@941e8160817b60df0a4fab981ea9e9e2ebe054b6` 已推送。制品哈希见 `release-sources.json`。
- npm 与最终部署：单独以 registry 的版本记录和下方部署证据为准；构建通过不等于已发布或已完成实服验证。

## 已授权的首次上线观察

用户在完成停止期间的离线验收后，明确授权升级并运行。部署先备份原配置、凭据、Memory 与账本，再加载 0.4.0-next.1 核心和本地千灯纪包装包。宿主使用已有 fork 后续修复，不按 npm 版本号覆盖它。

实服已验证：原游戏账号登录、库存与魔力/技能频道、现代画面、移动、近战、施法尝试与服务端回执。另确认 Dungeon 已连接，原观察者窗口已启动，E3 参考音色的流式语音成功合成。匹配的 1.20.6 本地声音资源加载后为 1607 项、无缺失诊断。

观察到 Agent 会提交错误参数，也可能用失败观察做出过度判断；上述修正改善契约和证据呈现，不证明模型已学会所有玩法或战斗最优。QQ 和 B 站登录恢复由用户明确推迟，不算已恢复。
