# 试炼战斗状态反馈

- `MC_TRIAL_RESCUE status=downed player=<本机玩家 UUID> ...`：由千灯纪服务器扩展校验并转为通用核心的身体受限状态。不能根据低血或不移动自行推断倒地。
- `status=denied reason=downed`：仅延续本连接已经确认的自身倒地状态，不制造新的倒地事件。
- `status=revived`：仅释放已确认的自身倒地状态。带其他玩家 ID、玩家聊天引文或重复字段均不能改变控制权。
- `seconds=10` 是救援协议字段，不用于十秒后自动恢复。等待真实复活回执；重生/新连接清除旧状态。

身体受限期间保留队列和可恢复断点，战斗终态为 `inhibited`，停止无效挥砍、移动及施法。新的事实只输出状态、原因和恢复条件；不把这段时间归为卡墙、寻路失败或战术败绩。

技能费用来自本连接服务端目录或明确能力读数。HUD 未提供静态费用时保留已经确认的费用；能力移除或连接重置后清除。动态剩余冷却未知仍保持未知，不能根据静态目录臆测可用时间。

自主战术读取 `frame.battlefield.actors`，候选为 `cast / engage / step / retreat`。候选来自当前 `actionPool`；模型保存程序、完成选择和真实命中分开验收。
