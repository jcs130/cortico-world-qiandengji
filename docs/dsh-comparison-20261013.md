# DSH / Cortico 双宿主试运行（2026-10-13）

## 交付边界

只发布一个 Cortico World：`cortico-world-qiandengji`，显示为“联机版我的世界”。
它依赖 `agent-mc-world` 中立核心与 `agent-mc-qiandengji` 中立服务器资料包。
通用模式默认 `serverPack: none`；千灯纪按配置显式开启。

DSH 项目 `jcs130/dsh-minecraft-agent` 更新为原生 0.2.0-rc.2 宿主适配器。
只安装核心、可选资料包及 DSH 插件，不安装 Cortico/N.E.K.O。
核心发行包不再包含 Cortico 适配器入口或实现；仓库里的 private 示例单独构建。
历史来源和许可证保留，不以删去署名伪装原创。

## 能力核对

| 能力 | 核心 / 资料包 | 宿主职责及限制 |
|---|---|---|
| 库存、导航、动作与方法 | 中立核心，SDK/MCP 同协议 | 宿主核对执行终态和目标条件 |
| 当前事实、回执、编号、去重、取消 | agent-mc/v1 | 真实宿主 turn/end，不用单次 RPC 冒充回合 |
| 密码认证 | 核心 scoped 配置，文件/环境变量/旧 DPAPI | 显式服务器+账号，认证与 spawn 均确认后才就绪 |
| 注册双密码 | opt-in repeatPassword | 私有配置开启，不能假定所有服务器相同 |
| 千灯纪资料 | 21 份指南和来源清单 | 维护者资料不是 Agent 的亲历记忆 |
| 公会/试炼/技能/魔力/大背包/保护/YSM | 可选服务器包 | 当前服务端协议为准；模型绑定需服务器授权 |
| 快战术 | 宿主 HostCombatDriver，typed-decision 端点可配置 | 当前战术候选端口来自千灯纪包；通用模式不能假称已支持 |
| 无模型回退 | 游戏规则控制持续运行 | 不扫描备用地址；无候选/超时/陈旧状态不执行模型动作 |
| 受阻建议、模型小动作 | 可导入宿主辅助实现 | 当前正式适配器没有自动挂接，不能声称已启用 |
| 主动学习 | 方法制品、脚本、验证和回执入口 | 生成、评价、记忆、复用由宿主承担；没有额外隐藏模型循环 |
| 模型与执行页面 | shared viewer 客户端静态页 /metrics | SDK 工具自动计量，模型由宿主上报，未知不填零 |

## 本地试运行

可米沿用原账号、人格、目标、方法和演出配置；鸣人使用独立账号、DSH profile、会话、数据及凭据目录。
两者主模型均为 qwen3.8-flash-next-iq3_s，显式快决策均为 StartLux-Decision-4B 的 /v1/systemone。
最新共享画面来源 mc-visual-console@75f15995，渲染源码基于 bd660d30；本地明确加载千灯纪与原版 1.20.6 音效资源。

DSH 使用正式 surface replacement 替换过期现场片段，保留追加式原始日志与 dsh_history 查询入口；按真实 llm/stream 统计实际调用。官方 tokenMeter 加上输出预留进行预算校验；显式启用原生 compaction-basic。管理页断开同时解除目标驱动、取消、保存与停身体。

试运行已观察到鸣人查询规则、加入公会、接面包委托与取用同伴提供的材料；可米恢复进食与反击僵尸，并有法术发送/战斗观察回执。这些是具体行为证据，不是长期稳定或最优战术结论。

已修复快速后台采样把每份完整战场写入行动日志的问题。保留实际决策、明确工具查询和执行回执。
还发现旧 `engine/` 忽略规则漏掉了服务器扩展自有源码，改为仅忽略根目录旧引擎，并将扩展源码纳入版本控制。依赖声明中的 `dist/` 同样需显式纳入；固定哈希的上游声明保留原始字节，避免 Windows 换行转换破坏校验。验收增加从 Git 暂存树导出后再离线构建，避免工作区未追踪文件掩盖缺失。

两个宿主都向同一模型网关发送各自独立的稳定会话标识。鸣人新增标识后的前三次完成请求首字延迟仍约 21–27 秒；其中一次输出 5,382 token、耗时约 165 秒。当前样本不能证明缓存或响应速度已改善；DSH 尚未得到缓存字段时页面保持未知，不推断为零。两边当前输出上限同为 6,000，后续需结合相同任务继续评估缩短输出和现场体积。

## 验证与发布

从完整 Git 暂存树导出、没有 Cortico 安装或源码的离线构建已通过 476 项、68 文件测试，含公开类型与禁网检查；公开声明闭包为 242 文件。DSH 原生会话及桥接另有 6 项通过。两边均已加载本地 0.4.0 候选核心与服务器包，DSH 适配器为 0.2.0。管理页断开曾实测暂停目标并取消回合，数分钟内没有自动复活；重新启动保留原会话及目标编号。
本轮只安装本地候选制品，不发布 npm。长时间游玩、快战术实际收益、YSM 真实绑定与画面、长期记忆和自主方法复用分别验收。
