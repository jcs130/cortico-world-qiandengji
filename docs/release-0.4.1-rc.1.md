# 0.4.1-rc.1 发布候选

本文件是准备说明，不能作为已发布、已加载或直播验收通过的证明。

## 发行单元

| 包 | 版本 | 用途 |
| --- | --- | --- |
| agent-mc-world | 0.5.7-rc.2 | 独立执行核心、SDK/MCP、锁定的共享可视化 |
| agent-mc-qiandengji | 0.5.0-rc.1 | 可选服务器实现与资料，不依赖 Cortico |
| cortico-world-qiandengji | 0.4.1-rc.1 | 唯一公开 World；Cortico 0.2.1 / API 6 |

根工作区与 `adapters/cortico` 均保持 private。旧 API 5 部署的兼容包单独准备，仅用于私有验收，不进入市场。

## 本次内容

- 与 Cortico 0.2.1 的 `webUi`、API 6、离线 `describe.json` 对齐。自描述工具来自实际 Mineflayer、Java 和可选服务器实现；默认工具按配置裁剪。
- 共享可视化锁定上游提交及输入 SHA-256，包含 1.21.1 的 3707 份原版音频、1.20.6 的 3681 份原版音频及两个版本各 8 首公共原创 BGM。素材保留原始来源，游戏素材不因代码 MIT 许可而变成原创素材。
- 音频目录与原始资源校验和一起分发；播放诊断区分无资源、未启用、等待浏览器授权和实际播放。
- 水中显式按键程序保有输入控制权，结束或取消时清理，避免被被动踏水逻辑覆盖。真实脱困仍需现场验收。
- 合入上游的显式浏览器选择修复；离线截图可通过 `AGENT_MC_BROWSER_EXECUTABLE` 指定已安装浏览器，不依赖其他产品的私有路径。
- 安装包仅保留一份编译后的 viewer，不携带输入压缩包、重复中间目录、私有人设、YSM 角色、模型凭据、个人记忆或部署状态。

## 发布前检查

1. 核对三个仓库远程 main、npm 已发布版本与本次候选来源。
2. 共享可视化完整测试、类型检查和两个版本实际构建；校验音频与公共音乐闭包。
3. 核心完整测试、类型、声明、构建与锁定资源校验；对真正打出的安装包运行 `verify:release`。
4. World 完整测试、类型与构建；在隔离消费者中使用官方 Cortico 0.2.1 的 dry mount 和 self-description 检查。
5. 分别检验 SDK/MCP、服务器资料包、公开 API 6 World 与私有 API 5 兼容装配；默认不连接游戏或推理服务。
6. 保存产物 SHA-256、测试证据、源代码提交、加载状态及未验证项。

经明确发布授权后，依赖按核心、可选服务器包、公开 World 的顺序发布，预发布版本使用 `next` 标签。当前不执行 npm 或 Market 发布。

## 部署与回退

升级前保存扩展清单、锁文件、原安装包及部署配置、会话、目标、记忆和账本。API 6 公共包不能直接替换 API 5 现役包；先核对宿主版本，或使用单独的私有 API 5 兼容候选。

直播中断仍需本线程对应范围的明确授权。同次恢复原连接和循环；失败时恢复原清单、锁和安装包，再验收原目标及身体控制。发布包不选择或更改部署者的模型、密钥、音色和游戏账号。

现场待验收：宿主启动时正确捕获 1611 条 1.21.1 数字音效注册项，实际服务端音效播放，以及水中操作与离水/传送后的画面表现。离线通过和网页热更新不替代这些现场证据。
