# 当前 Cortico 公共契约

本次源码候选使用 World API 6，对照官方 Cortico 0.2.6。主模型、人格、个人记忆及后台认知策略归宿主管理，不修改 Cortico 主框架。

## 数据目录

本 World 的数据放在部署 `dataDir/mymc/` 下。身体、游戏账本、方法库、网站身份与隔离练习使用同一个独立根目录。页面的存储键使用 `mymc-*`；实际 Minecraft 维度、玩家原话和证据编号不改名。

旧版本把游戏文件直接放在部署数据根目录。升级后若发现旧资料，World 保持可供操作员查看，先等待迁移，不连接一个空记忆的新身体。在 World 的“旧数据迁移”面板：

1. 查看最新清单；只包括旧 Minecraft / 本 World 的账本和明确的旧网站、练习目录。
2. 确认复制。清单变化或目标内容冲突时先核对，不覆盖已有文件。
3. 复制成功后重新构造 World，再按实际服务器连接与认证结果判断可操作。

原文件保留。共享核心负责散列校验、逐文件独占落盘、冲突和中断恢复；本适配器只选择旧文件名。会话、人格 Memory、宿主配置、未知文件及连接租约不进入迁移清单。旧身份文件中的明确绝对引用保持原样，仍指向留存的原文件；迁移不会换账号、建号或更换密码。网站身份继续遵守官方私有文件协议，不进入公开包或提示词。它与可替换模型服务的 `.env` 密钥引用分开管理。

## 可选快决策

默认关闭额外推理。标准 Cortico 没有私有的 `host.decisions` 或 `decision-providers` 选择器，本包不读取这些接口。

需要时，在本 World 的“快决策服务”配置完整的 `state/questions` 服务地址、模型名及部署 `.env` 的密钥变量名。普通聊天端点不能代替这个协议。例如局域网服务可以使用：

```json
{
  "decisionService": {
    "enabled": true,
    "endpoint": "http://YOUR_LAN_HOST:4000/v1/systemone",
    "model": "StartLux-Decision-4B",
    "apiKeyEnv": "MC_DECISION_KEY",
    "timeoutMs": 1000
  }
}
```

真实密钥由 `WorldContext.secret()` 读取，不写入 JSON。旧配置若已明确填写独立服务地址，可以继续使用；只有私有 provider id 的配置需要操作员填写对应服务，不能自动猜测。

`mymc_choose` 按需请求；战斗连续选择还需显式启用原战术开关。等待和失败不会停止原身体控制器。服务只返回候选概率，执行仍经核心检查现场、权限、冷却和控制权。服务请求及结果通过本 World 自己的观测端口展示，不订阅宿主内部调试流。缺失 token / 缓存计数保持未知；计数不完整时不伪造完整用量分类。

## 可选方法练习

练习通过公共 `WorldHost.cognition.request({brief, tools, hint:{rounds}})` 请求宿主。Persona 决定上下文、真实模型、轮数和预算；`rounds` 是建议，不是强制限制。每项配置的请求预算不等于供应商实际模型调用总量。

当前公共接口没有取消远端认知请求的契约。取消会停止本地等待并拒收迟到结果；原请求尚未结束时不发起同实例的下一次请求，不宣称供应商计算已经停止。停止练习不自动采用候选、重放动作或改变当前游戏身体。需要严格控制远端并发和计算预算时，由宿主 Persona 实现对应策略。

## 观测与部署

思考和工具观测使用公共 `outputTap`、`onRunPhase` 和本 World 的执行回执，不连接 `/ws/debug`，不读取宿主对话文件。

源码验证、打包安装、加载和实际游戏效果分别验收。API 5 私有兼容部署与公共 API 6 发行包分开记录，安装候选不等于已在可米实例加载。主动暂停或停用的游戏保持原状态，部署仍需本次范围匹配的授权。
